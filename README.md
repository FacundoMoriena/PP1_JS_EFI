Concesionaria EFI

Temática:
La temática elegida para el trabajo integrador final corresponde al sistema de una concesionaria de vehículos. La aplicación permite buscar y filtrar vehículos según distintos parámetros, así como agregar a una lista de favoritos aquellos que resulten de interés. A su vez, incluye un modo administrador que habilita la creación, edición y eliminación de vehículos en la base de datos.

API:
Utilizamos una API desarrollada con FastAPI y desplegada mediante FastAPILCloud.

Ejecución en entorno local:
Pasos para ejecutar la aplicación en local:

  -npm install

  -npm run dev

  -npm start
